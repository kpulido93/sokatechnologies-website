# Assets web

Esta carpeta contiene imagenes y recursos visuales para paginas publicas de WordPress. Los assets deben reforzar una marca B2B tecnologica, sobria, confiable y moderna: tecnologia clara para operaciones empresariales reales.

## Estructura

```text
assets/web/
assets/web/hero/
assets/web/services/
assets/web/cases/
assets/web/blog/
assets/web/contact/
assets/web/errors/
```

## Hero principal

Guardar en `assets/web/hero/` las imagenes o composiciones para el primer bloque de la Home y landings principales.

Recomendaciones:

- Formato WebP optimizado.
- Tamano fuente aproximado: 1600 x 900 px o 1920 x 1080 px.
- Peso objetivo: menos de 450 KB.
- Visual sobrio, tecnico y claro.
- Evitar fotos corporativas genericas, manos estrechandose, oficinas sin contexto o futurismo exagerado.

## Servicios

Guardar en `assets/web/services/` imagenes para:

- Software a medida.
- Automatizacion.
- Sitios web WordPress.
- Dashboards.
- Infraestructura.
- Soporte.

Recomendaciones:

- Usar composiciones abstractas, diagramas simples, interfaces anonimizadas o ilustraciones tecnicas sobrias.
- No mostrar pantallas reales de clientes.
- Mantener estilo visual consistente entre servicios.
- Peso objetivo por imagen: menos de 250 KB.

## Casos

Guardar en `assets/web/cases/` recursos para casos anonimizados.

Reglas:

- No incluir nombres, logos, dominios, emails, tickets ni datos reales de clientes.
- Usar sectores genericos: empresa de servicios, equipo comercial B2B, operacion regional, etc.
- Usar imagenes conceptuales o mockups anonimizados.
- Evitar metricas exactas si no estan aprobadas.

## Blog

Guardar en `assets/web/blog/` imagenes para entradas del blog.

Recomendaciones:

- Mantener una linea visual consistente.
- Evitar imagenes decorativas sin relacion con el tema.
- Usar nombres claros: `blog-automatizacion-procesos.webp`, `blog-dashboard-operaciones.webp`.
- Incluir texto alternativo al cargar en WordPress.

## Contacto

Guardar en `assets/web/contact/` imagenes para la pagina de contacto.

Recomendaciones:

- Representar diagnostico, conversacion tecnica o inicio de proyecto sin datos reales.
- No incluir telefonos, emails internos o datos de cPanel.
- Peso objetivo: menos de 250 KB.

## Errores

Guardar en `assets/web/errors/` imagenes para 404 u otros estados.

Recomendaciones:

- Imagen ligera y no invasiva.
- Mensaje visual sobrio.
- Evitar tono de juego, memes o ilustraciones demasiado informales.

## Licencia y confidencialidad

- Usar solo recursos propios, generados internamente o con licencia comercial clara.
- Registrar la fuente o licencia si no es un asset propio.
- No subir fotos con personas identificables sin autorizacion.
- No incluir datos reales de clientes, proveedores, usuarios o infraestructura.
- Revisar metadatos antes de versionar o subir a WordPress.
