# Iconos

Esta carpeta contiene iconografia propia o aprobada para la web de SokaTechnologies.

## Iconos requeridos

| Servicio | Nombre recomendado |
|---|---|
| Software a medida | `icon-software-a-medida.svg` |
| Automatizacion | `icon-automatizacion.svg` |
| Sitios web WordPress | `icon-wordpress-web.svg` |
| Dashboards | `icon-dashboards.svg` |
| Infraestructura | `icon-infraestructura.svg` |
| Soporte | `icon-soporte.svg` |

## Formato recomendado

- SVG optimizado.
- ViewBox consistente, preferiblemente `0 0 24 24` o `0 0 32 32`.
- Trazos con grosor consistente, por ejemplo 1.75 o 2 px.
- Color mediante `currentColor` cuando sea posible.
- Sin scripts, fuentes embebidas ni metadatos innecesarios.

## Reglas visuales

- Mantener el mismo grosor visual en todos los iconos.
- No mezclar iconos outline con iconos filled salvo que exista una decision visual documentada.
- No combinar estilos de librerias distintas sin revision.
- Evitar iconos demasiado futuristas, gaming o decorativos.
- Priorizar formas simples, tecnicas y legibles en tamanos pequenos.

## Uso en WordPress

- Cargar SVG solo si el flujo de WordPress lo permite de forma segura y aprobada.
- Si se usa PNG como fallback, conservar el SVG fuente versionado cuando sea propio.
- Incluir texto alternativo o etiqueta accesible cuando el icono aporte informacion.
- Marcar como decorativo si el icono no transmite informacion adicional.
