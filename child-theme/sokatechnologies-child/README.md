# SokaTechnologies Child Theme

Child theme para la web pública de SokaTechnologies.

## Propósito

Mantener personalizaciones propias sin modificar el tema padre.

## Instalación

1. Confirmar tema padre instalado.
2. Editar `style.css`.
3. Reemplazar:

```css
Template: parent-theme-folder-name

por el nombre exacto de la carpeta del tema padre.

Crear zip de sokatechnologies-child.
Subir desde WordPress Admin > Appearance > Themes > Add New.
Activar child theme.
Validar sitio.
Reglas
No copiar código del tema padre.
No guardar secretos.
No incluir credenciales.
No agregar lógica compleja en functions.php.
No instalar scripts externos sin revisión.
Mantener cambios pequeños.
Validación
Home carga correctamente.
Menú funciona.
Estilos cargan.
No hay errores PHP visibles.
Responsive validado.
Admin sigue funcionando.
