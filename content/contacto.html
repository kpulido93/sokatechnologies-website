Qué enviar para iniciar

  • Proceso o problema que quieres mejorar.
  • Herramientas, archivos o sistemas actuales.
  • Errores, demoras o riesgos que necesitas reducir.
  • Reportes, controles o indicadores que esperas obtener.
  • Restricciones de seguridad, cumplimiento o confidencialidad.

Tipos de diagnóstico

Diagnóstico de software

Para aplicaciones internas, portales, integraciones, automatizaciones o herramientas operativas.

Diagnóstico de datos

Para dashboards, reportes, consolidación de información, indicadores y trazabilidad.

Diagnóstico técnico

Para infraestructura cloud/on-prem, respaldos, monitoreo, WordPress o continuidad operativa.

Qué ocurre después

Revisión inicial

Confirmamos si el caso encaja con nuestras capacidades y qué información hace falta.

Diagnóstico

Analizamos proceso, usuarios, datos, herramientas, riesgos y resultado esperado.

Ruta propuesta

Planteamos fases, entregables, exclusiones, criterios de aceptación y soporte posible.

Nota de confidencialidad

El primer contacto debe incluir solo contexto general. No compartas credenciales, respaldos, bases de datos, información de clientes, tokens ni accesos. Cualquier revisión sensible requiere un alcance previamente acordado.
