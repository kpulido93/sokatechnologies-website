# sokatechnologies-website

Base inicial del repositorio para la web pública de SokaTechnologies.

## Objetivo

Preparar una estructura mínima, profesional y agnóstica de framework para documentar decisiones, organizar el contenido y facilitar la implementación posterior del sitio.

## Alcance actual

- Sin framework seleccionado.
- Sin dependencias instaladas.
- Sin `package.json`.
- Sin código funcional innecesario.
- Con documentación inicial de arquitectura, despliegue, seguridad y contenido.

## Estructura

```text
docs/       Documentación base del proyecto
public/     Activos públicos estáticos
scripts/    Automatizaciones y utilidades futuras
src/        Código fuente y contenido del sitio
tests/      Pruebas futuras
```

## Documentación

- `docs/architecture.md`: criterios y estructura técnica inicial.
- `docs/deployment.md`: consideraciones de despliegue y operación.
- `docs/security.md`: baseline de seguridad para el sitio público.
- `docs/decisions.md`: registro de decisiones iniciales.
- `docs/content-strategy.md`: enfoque editorial y páginas prioritarias.

## Próximos pasos sugeridos

1. Elegir framework y pipeline de build.
2. Definir páginas prioritarias y arquitectura de contenido.
3. Formalizar decisiones técnicas y de hosting.
4. Implementar la primera versión del sitio sobre esta base.
