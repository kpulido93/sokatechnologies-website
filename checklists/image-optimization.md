# Checklist de optimizacion de imagenes

Usar este checklist antes de versionar assets o cargarlos en WordPress.

## Formatos

- [ ] Logos e iconos en SVG optimizado cuando sea posible.
- [ ] Favicon en PNG cuadrado de 512 x 512 px.
- [ ] Apple touch icon en PNG de 180 x 180 px.
- [ ] Imagenes web en WebP optimizado.
- [ ] JPG solo para fotografia cuando WebP no sea viable.
- [ ] PNG solo cuando se necesite transparencia o compatibilidad concreta.

## Dimensiones recomendadas

- [ ] Open Graph: 1200 x 630 px.
- [ ] Hero: 1600 x 900 px o 1920 x 1080 px.
- [ ] Servicio: entre 900 x 600 px y 1200 x 800 px.
- [ ] Blog: 1200 x 675 px o proporcion consistente.
- [ ] Contacto: 1200 x 800 px como referencia.
- [ ] Error 404: 1200 x 800 px como maximo razonable.

## Pesos maximos recomendados

- [ ] Logo SVG: menos de 50 KB.
- [ ] Favicon o Apple touch icon: menos de 100 KB.
- [ ] Open Graph: menos de 350 KB.
- [ ] Hero: menos de 450 KB.
- [ ] Imagen de servicio: menos de 250 KB.
- [ ] Imagen de blog: menos de 300 KB.
- [ ] Imagen de contacto o error: menos de 250 KB.

## Licencia

- [ ] El asset es propio, generado internamente o tiene licencia comercial clara.
- [ ] La fuente o licencia esta documentada si aplica.
- [ ] No se usa una imagen descargada sin permiso.
- [ ] No se usan logos de terceros sin autorizacion.

## Confidencialidad

- [ ] No hay nombres de clientes reales.
- [ ] No hay logos de clientes reales.
- [ ] No hay emails, usuarios, tickets ni dominios internos.
- [ ] No hay capturas reales de sistemas sin anonimizar.
- [ ] No hay metricas privadas ni datos de negocio.
- [ ] No hay metadatos sensibles.

## Texto alternativo

- [ ] El texto alternativo describe la funcion de la imagen.
- [ ] El texto alternativo no repite texto cercano sin aportar valor.
- [ ] Las imagenes decorativas se marcan como decorativas cuando el flujo lo permita.
- [ ] No se incluyen palabras clave forzadas.

## Revision final

- [ ] La imagen se ve nitida en desktop.
- [ ] La imagen se ve bien en tablet.
- [ ] La imagen se ve bien en movil.
- [ ] No genera scroll horizontal.
- [ ] No tapa texto ni botones.
- [ ] El contraste es suficiente.
- [ ] El asset esta en la carpeta correcta del repo.
