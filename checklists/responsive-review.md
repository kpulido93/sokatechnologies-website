# Checklist de revision responsive

Usar este checklist para validar cambios visuales en escritorio, tablet y movil antes de publicar o migrar CSS al child theme.

## Desktop

- [ ] El contenido no queda demasiado ancho.
- [ ] La jerarquia de H1, H2 y H3 es clara.
- [ ] Las secciones tienen suficiente aire visual.
- [ ] Las grillas mantienen alineacion consistente.
- [ ] Header y footer no se ven vacios ni saturados.
- [ ] Los CTAs estan visibles sin resultar invasivos.
- [ ] No hay elementos superpuestos.

## Tablet

- [ ] El layout aprovecha el ancho sin quedar comprimido.
- [ ] Las columnas se reorganizan de forma natural.
- [ ] El hero mantiene jerarquia clara.
- [ ] Las tarjetas tienen alturas y espacios coherentes.
- [ ] La navegacion no invade el contenido.
- [ ] Formularios y CTAs son faciles de usar con tactil.
- [ ] No hay scroll horizontal inesperado.

## Movil

- [ ] La Home se lee correctamente en ancho movil.
- [ ] No hay texto cortado, solapado o fuera de pantalla.
- [ ] Los botones tienen area tactil suficiente.
- [ ] Las secciones tienen padding adecuado.
- [ ] Las grillas pasan a una columna cuando corresponde.
- [ ] Los CTAs siguen visibles sin ocupar demasiado espacio.
- [ ] No hay imagenes que tapen texto.

## Header

- [ ] El logo se ve nitido y no queda deformado.
- [ ] El menu principal funciona en movil.
- [ ] El menu principal funciona en tablet.
- [ ] El menu principal funciona en desktop.
- [ ] No aparece `Sample Page`.
- [ ] Los enlaces principales respetan el orden aprobado.
- [ ] No hay enlaces hacia `localhost`, `127.0.0.1` o rutas internas.
- [ ] Hover y focus son visibles.

## Hero

- [ ] El H1 cabe correctamente en movil.
- [ ] El texto introductorio no supera un largo razonable.
- [ ] Los botones se apilan o ajustan correctamente.
- [ ] La imagen o elemento visual no tapa texto.
- [ ] El hero deja ver continuidad hacia la siguiente seccion.
- [ ] No hay decoracion que genere scroll horizontal.

## Cards

- [ ] Las tarjetas pasan a una columna en movil.
- [ ] En tablet, la grilla no queda comprimida.
- [ ] En desktop, la grilla conserva alineacion y ritmo.
- [ ] Los textos largos no rompen la altura ni se superponen.
- [ ] Las tarjetas con menos contenido no se ven defectuosas.
- [ ] Los enlaces o botones dentro de tarjetas son tactiles en movil.

## Formularios

- [ ] Los campos ocupan el ancho adecuado en movil.
- [ ] Las labels no se pierden ni quedan cortadas.
- [ ] El boton de envio es facil de tocar.
- [ ] Los mensajes de error se ven cerca del campo correspondiente.
- [ ] El mensaje de exito no rompe el layout.
- [ ] No se oculta informacion legal necesaria.
- [ ] No se solicitan datos sensibles.

## Footer

- [ ] Las columnas pasan a una lectura vertical clara en movil.
- [ ] Los enlaces son faciles de tocar.
- [ ] Los datos de contacto no se cortan.
- [ ] Los textos legales son legibles.
- [ ] No hay enlaces genericos del tema padre.
- [ ] El footer mantiene contraste suficiente.

## Validacion final

- [ ] Probar al menos un ancho movil estrecho.
- [ ] Probar al menos un ancho tablet.
- [ ] Probar al menos un ancho desktop.
- [ ] Confirmar que no hay errores PHP visibles.
- [ ] Confirmar que el admin de WordPress sigue accesible si se hicieron pruebas locales.
- [ ] Confirmar que no se tocaron WordPress core, plugins, uploads ni produccion.
