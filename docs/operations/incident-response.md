# Incident Response

## Objetivo

Responder incidentes operativos con rapidez, registro y aprendizaje posterior.

## Activacion

Usar este proceso cuando exista caida, perdida de servicio, riesgo de seguridad o impacto fuerte para el usuario final.

## Flujo de respuesta

1. Detectar o recibir alerta.
2. Confirmar impacto y severidad.
3. Asignar lider de incidente.
4. Contener o mitigar primero.
5. Comunicar estado y siguiente actualizacion.
6. Cerrar con causa raiz preliminar y acciones siguientes.

- Documentar aprendizajes.
