# Codex Workflow

## Objetivo

Definir como usar Codex para editar documentacion o apoyar trabajo tecnico sin perder control operativo.

## Cuando usar Codex

- Crear borradores estructurados de documentos internos.
- Mejorar claridad, consistencia o formato de procesos existentes.
- Proponer checklists, tablas o plantillas.
- Ayudar a revisar que no haya informacion sensible en cambios nuevos.

## Flujo obligatorio

1. Indicar documento a crear o modificar.
2. Explicar objetivo del cambio.
3. Proponer estructura breve.
4. Revisar riesgos de confidencialidad.
5. Ejecutar cambio.
6. Resumir archivos afectados, riesgos y siguientes pasos.

## Reglas de uso

- No pedir a Codex que invente datos reales de clientes.
- No pegar secretos, tokens ni credenciales en prompts.
- Validar manualmente cualquier contenido legal, fiscal o contractual.
- Revisar que la salida sea realmente accionable antes de guardar.

## Prompt base sugerido

> Crea o actualiza este documento con tono profesional y accionable. Usa checklists y tablas. No incluyas secretos ni datos reales de clientes.
