# Proposal Template

## Objetivo

Usar una estructura comun para propuestas comerciales que reduzca ambiguedad y haga visibles alcance, exclusiones y condiciones.

## Estructura base

1. Resumen ejecutivo
   - Problema detectado
   - Objetivo del proyecto
   - Resultado esperado
2. Alcance
   - Incluye
   - No incluye
   - Dependencias del cliente
3. Entregables
   - Entregable 1
   - Entregable 2
4. Plan de trabajo
   - Fases
   - Hitos
   - Supuestos de calendario
5. Inversion
   - Modelo de precio
   - Forma de pago
   - Vigencia de la propuesta
6. Riesgos y supuestos
7. Proximos pasos

## Checklist antes de enviar

- El problema esta redactado en terminos de negocio.
- El alcance tiene limites claros.
- Las exclusiones no quedan implícitas.
- El cliente sabe que aprobaciones debe dar.
- La propuesta no promete integraciones, volumen o soporte no cotizado.

## Nota

Si la propuesta incluye temas contractuales, fiscales o regulatorios, recomendar validacion especifica antes de cierre.
