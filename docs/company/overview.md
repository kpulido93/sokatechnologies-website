# Company Overview

## Objetivo

Definir de forma breve que hace SokaTechnologies, para quien trabaja y bajo que criterios opera.

## Resumen base

| Tema | Definicion inicial |
| --- | --- |
| Tipo de empresa | Software B2B pequeno en etapa inicial. |
| Enfoque | Proyectos a medida, automatizacion y mejora operativa para empresas. |
| Cliente ideal | Equipos que necesitan software util, entregado con claridad y sin sobreingenieria. |
| Modelo de trabajo | Discovery, propuesta, ejecucion por hitos y soporte posterior. |
| Diferenciadores esperados | Cercania, velocidad razonable, comunicacion clara y foco en resultado de negocio. |

## Principios operativos

- Resolver problemas concretos antes que vender tecnologia por si misma.
- Documentar decisiones importantes para reducir dependencia de memoria informal.
- Evitar compromisos comerciales o tecnicos que el equipo no pueda sostener.
- Mantener alcance, entregables y soporte por escrito.

## Cuando actualizar este documento

- Cambio de posicionamiento o segmento objetivo.
- Incorporacion o retiro de una linea de servicio.
- Cambio relevante en modelo comercial o de delivery.
